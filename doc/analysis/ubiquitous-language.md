# Ubiquitous Language

| Termine | Significato |
|---------|------------|
| **Customer** | Utente che richiede consegne tramite drone |
| **Delivery Order** | Richiesta di consegna: pacco, luoghi, tempistica, stato |
| **Package** | Oggetto da consegnare, caratterizzato da peso (kg) |
| **Pickup Location** | Luogo di ritiro (indirizzo + coordinate GPS) |
| **Delivery Location** | Luogo di consegna (indirizzo + coordinate GPS) |
| **Delivery Window** | Finestra temporale: immediata o programmata |
| **Drone** | Veicolo aereo autonomo, con un peso massimo trasportabile |
| **Drone Status** | AVAILABLE, IN_FLIGHT |
| **Delivery** | Trasporto di un pacco dal pickup al delivery location tramite drone |
| **Delivery Status** | SCHEDULED, DRONE_ASSIGNED, IN_TRANSIT, DELIVERED, FAILED |
| **Route** | Percorso calcolato dal pickup al delivery location |
| **ETA** | Tempo stimato di arrivo |
| **Tracking** | Monitoraggio real-time di posizione drone e stato consegna |
| **Place Order** | Customer crea una richiesta di consegna |
| **Confirm Order** | Sistema conferma l'ordine dopo verifica disponibilita |
| **Cancel Order** | Customer annulla un ordine non ancora in transito |
| **Assign Drone** | Sistema assegna un drone disponibile a una delivery |
| **Dispatch Drone** | Drone parte verso il pickup location |
| **Pick Up Package** | Drone ritira il pacco |
| **Deliver Package** | Drone consegna il pacco a destinazione |
| **Track Delivery** | Customer consulta posizione drone e ETA in tempo reale |
| **Update Location** | Drone comunica la propria posizione GPS al sistema |
